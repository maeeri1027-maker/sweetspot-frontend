# Sweet Spot（スイーツ＆カフェ スポット管理アプリ）

SNS（X, Instagram, TikTok）等で見つけた「行ってみたいお店」を整理・管理し、おでかけ時に最適なスポットをすぐに見つけられるWebアプリケーションです。

- **本番Webサイト（フロントエンド）:** https://sweetspot-frontend.vercel.app/
- **APIサーバー（バックエンド）:** https://sweetspot-7kzg.onrender.com/api/spots

---

## 💡 開発背景と解決したい課題

### 開発背景

X（旧Twitter）、Instagramのショート動画、TikTokなどで「近場のおいしいお店」の情報に触れる機会が増えています。
従来はGoogleマップ等にピンを立てて保存していましたが、実際に「今日どこかに行こう」となった際、マップ上のピンだけでは**リストとして一覧化されておらず、カテゴリやその時の気分（「スイーツ」「カフェ」「行った／気になる」など）で比較・絞り込みがしづらい**という課題を感じていました。

### 本アプリによる解決策

- **カード＆グリッド形式の一覧化:** 保存したスポットを整理されたカード形式で視覚的に比較・選定できます。
- **タグ・ステータス検索:** 「行った」「気になる」「時間があれば」といった状態や、「カフェ」「スイーツ」などのカテゴリによる即時フィルタリング機能を提供します。
- **訪問記録・レビュー保存:** 行った日付や感想・メモを記録でき、自分だけのグルメガイドを作成できます。

## ✨ 主要機能一覧

- **ユーザー認証機能**
  - 会員登録 / ログイン・ログアウト（JWT認証・Security実装）
- **スポット管理（CRUD機能）**
  - スポット一覧表示（リストビュー / グリッドビュー切り替え機能）
  - スポット新規登録（画像アップロード機能・プレビュー表示機能）
  - スポット詳細表示・編集・削除機能
- **検索・絞り込み機能**
  - カテゴリタグ（#カフェ、#スイーツ など）によるフィルタリング
  - 訪問ステータス（行った / 気になる / 時間があれば）による絞り込み
  - ソート機能（最新順 / 古い順 / 五十音順）
- **マップ連携**
  - 登録住所から Google Maps へのダイレクト遷移リンク生成
